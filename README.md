# Omkar Deshmukh – Portfolio & Achievements

A modern, interactive portfolio and digital showcase for Omkar Deshmukh. This project features a visually engaging gallery of awards, hackathon victories, research showcases, and academic milestones. Each achievement is presented with immersive image galleries, video demos, and direct links to live projects or reports. The site is fully responsive, with smooth navigation, keyboard controls, and a focus on accessibility and user experience.

## Features
- Awards & Achievements gallery with images, videos, and links
- Modal system with ESC/arrow key navigation
- Responsive, mobile-friendly design
- Theming (light/dark mode)
- Fast, smooth animations

## Quick Start
1. Clone the repo
2. Open `index.html` in your browser
